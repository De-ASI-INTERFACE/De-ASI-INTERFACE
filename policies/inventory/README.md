# Inventory

Structured runtime state that policy documents reference. Editing anything here follows the same PR gates as the policies themselves.

- `agents.yaml` — the AI agent inventory required by POLICY-010 §3.
- `validation-log.md` — the independent validation record required by POLICY-010 §6.
- `sole-operator-exceptions.md` — the log required by POLICY-011 §4.
- `credentials.md` — the credential metadata inventory required by POLICY-011 §7 (never contains secrets).
